API Endpoints Reference

GET /api/books List all books with optional search, author, genre filters
Query Parameters: q (search query), author, genre, sort (id, title, author, rating, year), order (asc, desc)
GET /api/books/{id} Retrieve a single book with its ID, title, and author details
Path Parameter: id (integer) • Returns 404 if book is not found
POST /api/books Create a new book record
Request Body (JSON): {"title": "...", "author": "...", "genre": "...", "year": 2024, "rating": 4.5} (title and author required)
PUT /api/books/{id} Update an existing book record by ID
Path Parameter: id (integer) • Body: JSON fields to update
DELETE /api/books/{id} Delete a book record from database
Path Parameter: id (integer) • Returns 200 on success or 404
GET /api/authors Get summary of all authors and their published book counts
GET /api/stats Get library metrics (total books, unique authors, genres, avg rating)
